Tab by Host — Privacy Policy

Chrome extension that groups tabs by site host.

Last updated: 26 November 2026 · Extension version 1.1.0

Versione italiana ↓

Tab by Host does not collect, transmit or sell any data. It runs entirely in your browser: no server, no account, no telemetry, no remote libraries, no third-party code.

Summary

Does any data leave your device?No. The extension makes no network requests at all.
Is an account required?No.
Is there analytics or tracking?No.
Is anything synced to the cloud?No. Local storage only, never storage.sync.
Is page content read?No. The extension injects no scripts into pages.
Who can see your data?Only you, in the Chrome profile on this computer.

Data processed

The extension processes two sets of data, both stored locally on your device.

1. The rules you create — local storage

Kept until you delete them or uninstall the extension.

FieldContent
hostThe host you typed, e.g. staging.example.com
groupThe group name you chose
colorThe colour you chose
includeSubdomains, enabledTwo switches
idA random local identifier for the rule

This is exactly what you entered. Nothing else is added.

2. Operational state — session storage

Cleared automatically by Chrome when you close the browser.

  • Tab-to-group association: numeric tab, group and window identifiers
  • Group names, used to find the right group in each window
  • Counters: how many tabs matched, how many were updated, whether errors occurred

This exists so grouping survives Chrome suspending the extension's service worker, which can happen at any time.

What the extension does not do

Visited addresses are not stored. The extension reads a tab's address, extracts the host, compares it with your rules and discards the address. Paths, query strings, page titles and browsing history are never stored and never used for matching.

No page content is read. The manifest declares no content_scripts and no host_permissions: the extension technically has no access to passwords, cookies, forms or site text.

No network connections. The Content Security Policy includes connect-src 'none', which blocks any outgoing request at the browser level — even in the event of a bug.

Incognito windows are excluded ("incognito": "not_allowed").

Data you export yourself

Export JSON creates a file containing the hosts you configured. The file is saved wherever you choose; the extension never transmits it. Treat it like any other configuration file: if it contains internal company hosts, store it accordingly.

Deletion

Uninstalling the extension from chrome://extensions removes your rules and state. Tab groups already created remain in Chrome, because they belong to the browser and not to the extension.

Verifiability

You do not have to take this on trust. The source code is public, and these guarantees are enforced automatically on every change by a continuous integration check that fails if network calls, cloud storage, undeclared APIs or third-party runtime dependencies ever appear.

Dati trattati

1. Le regole che crei — archiviazione locale

Conservate finché non le elimini o disinstalli l'estensione: l'host che hai inserito, il nome del gruppo, il colore, due interruttori e un identificativo casuale. Sono esattamente i dati che hai digitato tu, nessun altro campo viene aggiunto.

2. Stato operativo — archiviazione di sessione

Cancellato automaticamente da Chrome alla chiusura del browser: associazione scheda-gruppo (identificativi numerici), nomi dei gruppi e contatori delle operazioni. Serve a far sopravvivere il raggruppamento alla sospensione del service worker da parte di Chrome.

Cosa non viene fatto

Gli indirizzi visitati non vengono memorizzati. L'estensione legge l'indirizzo di una scheda, ne estrae l'host, lo confronta con le regole e lo scarta. Percorsi, query string, titolo della pagina e cronologia non vengono mai salvati né usati per la corrispondenza.

Nessun contenuto delle pagine viene letto. Il manifest non dichiara content_scripts né host_permissions: l'estensione non ha tecnicamente accesso a password, cookie, moduli o testo dei siti.

Nessuna connessione di rete. La Content Security Policy include connect-src 'none', che impedisce qualunque richiesta in uscita a livello di browser.

Le finestre in incognito sono escluse.

Dati che esporti tu

Esporta JSON crea un file con i nomi degli host che hai configurato. Il file viene salvato dove scegli tu e l'estensione non lo trasmette da nessuna parte. Conservalo come gli altri file di configurazione.

Cancellazione

Disinstallare l'estensione da chrome://extensions elimina regole e stato. I gruppi di schede già creati restano in Chrome, perché appartengono al browser.

Verificabilità

Non devi fidarti sulla parola: il codice sorgente è pubblico e queste garanzie sono verificate automaticamente a ogni modifica da un controllo che fallisce se compaiono chiamate di rete, archiviazione cloud, API non dichiarate o dipendenze di terze parti.
